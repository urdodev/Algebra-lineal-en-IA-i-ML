# SCRIPT CONTENT

En este script se realizara una prueba con un modelo para asegurar que el dataset funciona y se pueda realizar con otros modelos facilmente, no tendra ninguna grafica, su unico uso sera de confirmación para seguir con la parte principal.

El modelo utilizado en este test será **DummyClassifier**, un modelo que predice siempre la clase mayoritaria sin aprender ningún patrón. Se ha escogido por la simpleza del modelo y para no solaparse con los otros 4 modelos.
